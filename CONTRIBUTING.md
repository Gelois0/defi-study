# Contribuir

Gracias por ayudar a mejorar este material de estudio. Se aceptan correcciones, nuevos recursos, aclaraciones técnicas y mejoras de estructura.

## Flujo de contribución

1. Para una propuesta amplia, abre un issue antes de trabajarla. Incluye el objetivo, el recurso o protocolo afectado y las fuentes.
2. Haz un fork o crea una rama desde `main` y limita el cambio a un tema concreto.
3. Edita los archivos Markdown conservando el idioma español, los enlaces descriptivos y el orden de lectura.
4. Abre un pull request con un resumen, el motivo del cambio y las fuentes consultadas.

## Estándar editorial

- Prioriza documentación oficial, estándares, términos legales, reportes y datos primarios.
- Diferencia hechos observables, afirmaciones de una empresa, interpretación y riesgos pendientes.
- Incluye fecha o periodo cuando cites métricas que pueden cambiar.
- No presentes TVL, oferta, usuarios registrados, APY anunciado o volumen bruto como prueba suficiente de adopción, liquidez o rentabilidad.
- Marca los enlaces pendientes de revisión y reporta enlaces rotos.
- Evita recomendaciones de inversión, promesas de rendimiento y lenguaje promocional.

## Seguridad y privacidad

No publiques secretos, claves, frases semilla, datos personales ni transacciones que expongan información privada. No propongas que otras personas conecten wallets o firmen operaciones con fondos reales como parte de una prueba documental.

## Licencia

Al enviar una contribución, aceptas que se distribuya bajo la licencia MIT de este repositorio.
