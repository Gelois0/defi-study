# Ethereum, stablecoins y DeFi

Material de estudio para entender la infraestructura de Ethereum, los flujos de stablecoins y dos operaciones DeFi concretas: lending con Morpho y provisión de liquidez con Meteora DLMM.

> **Enfoque:** análisis de mecanismos, riesgos y operación. No es una recomendación de inversión ni una ruta para trading direccional.

## Rutas

1. [Ethereum para fintech y stablecoins](ethereum-para-fintech-y-stablecoins.md) — transacciones, L2, tokens, emisores, exploración on-chain, MEV y privacidad.
2. [DeFi: Morpho y Meteora DLMM](ruta-defi-morpho-meteora.md) — secuencia de estudio, documentación oficial, análisis de riesgo y práctica gradual.

## Orden sugerido

1. Repasar la ruta de Ethereum: transacciones, EVM, tokens, wallets y redes.
2. Estudiar conceptos generales de DeFi y microestructura de mercado.
3. Analizar Morpho sin depositar: vault, curator, allocator, markets, oráculo, LLTV y liquidaciones.
4. Estudiar Meteora DLMM: bins, estrategia, fees, composición de posición y escenarios de precio.
5. Solo después de comprender el flujo, considerar pruebas pequeñas de depósito, retiro o provisión de liquidez.

Los libros sobre pagos y stablecoins dan contexto complementario; no son requisitos para empezar a analizar Morpho o Meteora.

## Criterio de investigación

- Priorizar documentación oficial, términos, contratos y datos verificables.
- Separar APR/APY base de incentivos temporales.
- No inferir adopción, seguridad, liquidez de salida ni rendimiento futuro desde una página comercial o un dashboard.
- Antes de interactuar, confirmar activo, red, contrato, permisos, costes, liquidez y ruta de recuperación.

## Cómo colaborar

El repositorio es público y acepta contribuciones mediante issues y pull requests. Para proponer cambios:

1. Abre un issue con el recurso, corrección o tema que propones, incluyendo enlaces y contexto.
2. Para cambios directos, crea una rama y envía un pull request describiendo los cambios y las fuentes.
3. Prioriza documentación primaria; identifica con claridad afirmaciones del emisor, datos observados e interpretación.
4. No incluyas claves, frases semilla, datos personales ni instrucciones para firmar transacciones con fondos reales.

Las contribuciones se publican bajo la licencia MIT del repositorio. Los enlaces pueden cambiar; reporta vínculos rotos o documentación obsoleta.
